why the card

the tablet has no way to be configured over the network: the link’s api only ever receives from the tablet, there is no usb disk mode, and wi-fi cannot be the channel because the wi-fi password is one of the things being set. so the card goes in a reader and this writes KEYS.ENV to it. the tablet reads that file once, applies it, then wipes and deletes it.

this cannot confirm the tablet read it. put the card back in and look for the tablet’s own “from the card” message.

# Catalyst Tab 0.1.0-preview.1 — 2026-10-17

This first published preview makes the accumulated `tab5-int` development available on GitHub.
It includes the portable Bezel UI, robot diagnostics over NT4, recorder, home/companion screens,
and the Catalyst Link PC service (Python package version 1.0.0). The existing assistant backend
still uses the documented Claude/API transports; this release does not migrate it to Codex.

## Verification

- ESP32-P4: ESP-IDF 5.5.1 build succeeds using the paired local esp-hosted 1.4.7 host component.
- Portable C: 4,678 checks pass with Visual Studio 2022 Build Tools.
- Catalyst Link: 163 tests pass, with one platform-dependent skip.
- Linux simulator and physical hardware were not tested for this release. No flash was performed.
- Test tooling now includes all portable modules. Two historical expectations were stale: the
  companion's current Tabi identity and exclusion of companion-only pet tools from technician
  requests. The updated check validates every tool's exact presence and rejects duplicates.

## Images and compatibility

The release ZIP contains bootloader, partition table, application and wake-word model, plus
`flash_args`, a merged image, and a checksum/provenance manifest. Build artifacts are created
from the release source, rather than copied from the stale tracked `firmware/` directory.

P4 uses SDIO RX_MAX_SIZE, paired with C6 esp-hosted 1.4.7 **packet mode** (streaming disabled).
The released P4 configuration leaves BLE/NimBLE disabled. Pair with the Wi-Fi-only C6 preview;
the unqualified BLE configuration in the developer's C6 checkout is not shipped. No dependency
major versions, rendering algorithms, memory ownership or NT4 write permissions change here.

The tablet only writes declared tunables, auto selection and camera LED settings. Its preflight
is advisory and cannot block robot startup or enable. Firmware release publication never
authorizes flashing hardware or enabling a robot.

For a full install, extract the archive and use its flash offsets; the merged image goes at 0x0.
A merged flash spans the NVS region and can erase saved settings. An app-only update at 0x10000
preserves settings only when the installed partition/model layout matches this release.
